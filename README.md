# 👑 Queens Of Change Foundation

A modern, responsive, and animated nonprofit website built to showcase the mission of empowering women and girls through education, mentorship, leadership, and opportunity.

---

## 🌸 Overview

**Queens Of Change Foundation** is a beautifully designed front-end web project that represents a real-world social impact organization.  
It focuses on storytelling, visual engagement, and emotional UI/UX to inspire visitors to take action.

This website highlights:
- The foundation’s mission
- Realistic impact metrics
- Programs and initiatives
- Journey timeline
- Volunteer and donation CTAs

## 🚀 Features

### 🎨 UI/UX
- Modern luxury-inspired design
- Smooth animations and scroll reveal effects
- Glassmorphism-style cards
- Elegant typography (Playfair Display + DM Sans)
- Gradient-based visual identity

### 🌗 Theme System
- Dark mode + Light mode toggle
- Persistent theme using localStorage
- Dynamic CSS variables for full theme switching

### 📱 Responsive Design
- Mobile-first approach
- Fully responsive grid system
- Optimized navbar for small screens
- Adaptive typography and spacing

### 📊 Interactive Elements
- Animated counters for impact stats
- Scroll-triggered reveal animations
- Hover effects on cards and buttons
- Parallax-style hero animation

### 🧭 Sections Included
- Hero Section
- About Section
- Impact Metrics Dashboard
- Statistics Strip
- Programs / Pillars
- Journey Timeline
- Volunteer / Donation CTA
- Footer with links
